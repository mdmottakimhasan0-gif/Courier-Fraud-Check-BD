# User Guide

## Merchant Workflow
1. Register a merchant account.
2. Verify email.
3. Log in to the merchant portal.
4. Configure billing and subscription.
5. Add merchant courier credentials through protected management workflows.
6. Search Bangladeshi phone numbers from the fraud search workspace.
7. Review risk score, confidence, delivery totals, provider status, and history.

## Account Security
- Use strong passwords.
- Review active sessions.
- Revoke unknown devices.
- Change password immediately after suspicious activity.
