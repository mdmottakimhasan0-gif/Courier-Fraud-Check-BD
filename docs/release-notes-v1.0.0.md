# Release Notes v1.0.0

Courier Fraud Check BD v1.0 is the first production release candidate.

## Highlights
- Production SaaS landing page.
- Live frontend/backend integration for auth, dashboard, search, billing, admin, health, and operational modules.
- Mock/demo data removed from active frontend surfaces.
- SEO metadata, robots, sitemap, manifest, 404, and global error handling.
- Production documentation pack.
- Verification target includes lint, typecheck, tests, and build.

## Security
- No GPL source code is included.
- Courier behavior remains independently implemented.
- Merchant credentials are designed for encrypted storage only.
