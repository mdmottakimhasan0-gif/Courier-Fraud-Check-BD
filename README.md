# Courier Fraud Check BD

Production-ready SaaS foundation for checking Bangladeshi courier delivery reliability.

## Project Boundary

All project files live under `D:\Courier-Fraud-Check-BD`.

## Milestone Status

- Milestone 0: Architecture documentation approved and locked.
- Milestone 1: Project foundation complete.
- Milestone 2: Backend core architecture complete.
- Milestone 3: Database design with Prisma complete.
- Milestone 4: Courier provider adapter layer complete.
- Milestone 5: Fraud search engine complete.
- Milestone 6: Authentication architecture complete.
- Next milestone: Not started. Requires user approval.

## Workspaces

- `frontend`: Next.js 15, React 19, TypeScript, Tailwind CSS foundation.
- `backend`: NestJS TypeScript API foundation.
- `shared`: Shared TypeScript contracts and constants.

## Commands

```bash
npm install
npm run lint
npm run typecheck
npm run build
```
